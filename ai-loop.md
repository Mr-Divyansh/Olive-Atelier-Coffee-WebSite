# AI-Assisted Development Workflow

Before any implementation work:

1. Read `README.md`, `PRD.md`, `design.md`, `architecture.md`, and `phases.md`.
2. Confirm which phase is approved and meets its acceptance criteria; do not begin a later phase without explicit approval.
3. Inspect the relevant existing code and project instructions before changing anything.
4. Make one focused change at a time and preserve working behavior.
5. Follow the documented Olive Atelier design system and content/asset rules.
6. Run only available, relevant lint, build, and test commands. Do not invent commands for tooling that is not present.
7. Inspect failures and fix root causes; report checks that were not available or not run.
8. Verify responsive behavior, keyboard access, reduced motion, content accuracy, and visual consistency when frontend code exists.
9. Update documentation when an approved implementation decision changes.
10. Never claim that an unrun test, build, visual check, asset verification, or legal review passed.

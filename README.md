# Olive Atelier — Restaurant & Café Website

**A D Web Studio concept project**

Olive Atelier is a premium restaurant and café website concept focused on warm visuals, editorial typography, authentic food photography, and a clean, responsive user experience.

The project aims to help a restaurant or café present its atmosphere, showcase its menu, and make it easier for visitors to explore the business, plan a visit, and get in touch.

> **Design direction:** Olive Atelier — Natural Premium  
> **Project status:** Responsive static concept prototype
> **Created by:** D Web Studio

---

## Project Overview

Olive Atelier is a proposed restaurant and café website designed around a natural, warm, and sophisticated visual identity.

The design uses warm ivory backgrounds, deep forest green accents, muted olive details, and elegant typography to create a welcoming hospitality experience without unnecessary visual effects or generic template styling.

The supplied desktop and mobile reference boards are visual design references, not a completed website or verified representation of a real business.

## Implemented Demo Experience

- Responsive editorial landing page with Olive Atelier wordmark and mobile navigation.
- A dedicated [About page](./about.html) based on the latest story-page reference, with a story hero, journey collage, values, concept quote, gallery, and contact section.
- Food-led hero, story, illustrative menu, atmosphere section, and filterable photo gallery.
- Demo reservation form with date/time/party-size validation and a clear no-booking-sent notice.
- Explicit placeholders for unconfirmed location, hours, and contact information.
- Keyboard focus styling, skip link, reduced-motion support, semantic labels, and responsive layouts.

**Important:** This is still a concept, not a verified business website. Dish descriptions, imagery, and the brand story are illustrative. No reservation service, real contact details, or actual venue information is connected.

## Design System

The project follows the **Olive Atelier — Natural Premium** design direction.

| Design token | Color | HEX |
|---|---|---|
| Background | Warm Ivory | `#F7F3E8` |
| Primary | Deep Forest Green | `#24382C` |
| Secondary | Muted Olive | `#7A8056` |
| Accent | Soft Brass | `#C6A56B` |
| Text | Espresso Brown | `#4A3024` |

The visual approach prioritizes readable typography, natural photography, balanced spacing, accessible contrast, and a consistent experience across screen sizes.

See [design.md](./design.md) for the complete design specifications.

## Current Project Status

**Prototype implementation**

The initial repository contained documentation only. The current prototype is implemented in `index.html`, `css/styles.css`, and `js/main.js`; it uses native browser technologies and has no package dependencies or build step.

## Technology Stack

The site uses **HTML, CSS, and vanilla JavaScript**. There is no framework, package manager, server, build tool, or environment variable.

### Setup Instructions

No installation is required. Open `index.html` or `about.html` in a browser. An internet connection is required for the remote Unsplash image URLs. The site is a static prototype; the reservation demo does not submit or store bookings.

## Content and Asset Policy

Before presenting Olive Atelier as a real business, confirm the business identity and obtain approved information.

The following details must not be invented or presented as verified facts:

- Business address and contact information.
- Menu items and prices.
- Opening hours.
- Customer reviews and testimonials.
- Awards, statistics, and promotional claims.
- Booking and ordering arrangements.

Stock photography and other demonstration assets must not be represented as photographs of the actual business. External image sources, licensing conditions, and attribution requirements must be checked before use.
